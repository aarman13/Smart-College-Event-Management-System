# Smart College Event Management System

A web-based College Event Management System developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.

## Features

- Student Registration and Login
- Admin Dashboard
- Event Creation and Management
- Event Registration
- Volunteer Management
- Search Functionality
- Email Notifications
- Attendance and Registration Tracking

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Project Modules

### Admin
- Manage Events
- Manage Students
- Manage Volunteers
- View Registrations

### Student
- Register/Login
- View Events
- Register for Events
- Track Registrations

## Installation

1. Clone the repository
2. Import the database into MySQL
3. Configure database connection in `db.php`
4. Run the project using XAMPP
